# Draw-Things Scripts

This is a workspace of different versions/iterations/concepts of a prompt randomizer/batch generator for the Draw Things app on iOS, iPadOS and MacOS. The most recent version of the Batch Generator is v14. That generator was vibe-coded using Claude, Gemini, ChatGPT and Kimi K3 in Copilot in VSCode. It was a mess... I wanted to start from scratch and do it myself. That iteration is called "randomizer.js". It is much simpler and more intuitive. Everything is on one screen. You can generate 1, 3, 5, 10 or 20 random images, all single female subjects for now, of several different nationalities, outfits, actions, etc. 

As this project has grown, I have decided to go in a slightly different direction and expand out each scene with object classes, having the script build a scene with multiple subjects or entities, opening up the possibility for very interesting results. For now, I have taken out the Draw Things architecture and will be focusing on the prompt generator, keeping everything in VSCode and printing the prompt to the console. Once everything looks good, I will bring the Draw Things architecture back in and make it a DT script again.

The current branch is "v2".
